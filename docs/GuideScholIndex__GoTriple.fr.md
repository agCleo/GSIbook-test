# GoTriple

GoTriple est une plateforme de découverte multilingue dédiée aux Sciences Humaines et Sociales (SHS). Elle offre un point d'accès unique pour la découverte et la réutilisation des ressources scientifiques pertinentes pour toutes les disciplines relevant du domaine des SHS : publications et données de recherche, descriptions de projets, profils d'auteurs et de chercheurs sont automatiquement importés depuis des agrégateurs et des fournisseurs de données, sémantiquement enrichis et liés dans la plateforme GoTriple.

## PROCESSUS D'INCLUSION
| Element | Description |
| :- | :- |
| Options d'inclusion | Si les publications ne sont pas déjà stockées dans les sources de données de GoTriple, la principale option pour être référencé consiste à enregistrer une nouvelle source de données via l'interface dédiée : https://pipeline.gotriple.eu/user/login?destination=/  |
| Processus de collecte des données  | Pour être référencé sur GoTriple, il est nécessaire de fournir un accès standard aux métadonnées standard, c'est-à-dire un dépôt OAI-PMH contenant des métadonnées conformes aux standards pris en charge par GoTriple.<br><br>Il est également possible d'envoyer un fichier au format OpenAIRE. |
| Formulaire pour les fournisseurs de données | https://pipeline.gotriple.eu/user/login?destination=/  |

## CONDITIONS MINIMALES
| Element | Description |
| :- | :- |
| Critères éditoriaux | Les ressources doivent appartenir au domaine des SHS. Elles peuvent prendre diverses formes : article, bibliographie, billet de blogue, rapport, périodique, prépublication, compte rendu, etc. |
| Formats de données | Données non collectées |
| Standards de métadonnées | Au choix : <br>Dublin Core<br>format OpenAIRE<br>modèle de données Europeana (EDM)<br>MARC21 (en cours d'élaboration) |
| Formats de métadonnées | Au choix : <br>XML<br>JSON au format OpenAire; plus d'informations ici : https://zenodo.org/records/5799514/files/result_schema.json  |
| Métadonnées minimales | Créateur de la ressource<br>Identifiant de la ressource<br>Titre de la ressource |
