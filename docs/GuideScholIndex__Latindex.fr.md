# Latindex

Latindex est un système d'information en ligne régional pour les revues académiques d'Amérique latine, des Caraïbes, d'Espagne et du Portugal. Il propose un système d'information bibliographique accessible gratuitement. Il comprend : 1) un répertoire contenant un inventaire complet des revues scientifiques affichant les données bibliographiques essentielles de chaque titre ; 2) un catalogue présentant une sélection de revues répondant à des critères de qualité internationaux. Latindex donne également accès au texte intégral d'environ 3 000 articles dans son domaine.

## CONDITIONS MINIMALES
| Element | Description |
| :- | :- |
| Critères éditoriaux | Pour figurer dans l'Annuaire, il suffit de remplir les conditions suivantes :<br>Offrir un contenu académique<br>Avoir une publication en cours<br>Avoir au moins un numéro publié<br>ISSN<br><br>Pour figurer dans le Catalogue, il faut :<br>Être indexé dans le Répertoire<br>Proposer un contenu en accès ouvert (gratuit ou payant)<br>Répondre à au moins 30 des 38 critères d'admissibilité<br>Répondre spécifiquement aux sept critères de base obligatoires<br><br>Les sept critères de base sont les suivants :<br>Informations sur les responsabilités éditoriales<br>Régularité de publication sur plus de deux ans<br>Informations sur les auteurs<br>Identification de l'organisme éditeur<br>Instructions aux auteurs pour la publication<br>Politique de publication<br>ISSN |
