# OPENAIRE_Graph

Le graphe OpenAIRE est une ressource ouverte qui agrège un ensemble de propriétés de données de recherche (métadonnées, liens) disponibles au sein de l'infrastructure OpenAIRE Open Science pour les financeurs, les organisations, les chercheurs, les communautés de recherche et les éditeurs. Il est accessible via des jeux de données publiés sur Zenodo et consultable via OpenAIRE EXPLORE.
