# Guide to Scholarly Indexes
This repository contains the files of the Guide to Scholarly Indexes, a documentation about indexes listing scholarly publications.

The Guide to Scholarly Indexes is a service of the [European Diamond Capacity Hub](https://edch.eu/) (EDCH) and is maintained by [Aix-Marseille University](https://www.univ-amu.fr/) / [OpenEdition](https://www.openedition.org/?lang=en). 

This EDCH service was created was developed collectively within the [CRAFT-OA](https://www.craft-oa.eu/) project. CRAFT-OA is an [OPERAS RI](https://operas-eu.org/) project coordinated by the [University of Göttigen](https://www.uni-goettingen.de/en/1.html).
